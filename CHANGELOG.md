## 1.3.0

### GetBox обновляется сам
- Новая версия ищется на GitHub при запуске и раз в 6 часов, скачивается в фоне и сверяется по SHA256 с файлом из релиза.
- В заголовке окна появляется кнопка «Обновить до X»: перезапустить сейчас или обновиться при выходе.
- После обновления — экран «Что нового» с переходом к новым возможностям; повторно открывается из настроек.
- Настройки → GetBox: версия, проверка вручную, фоновая загрузка, канал «Стабильный» / «Бета».

### Обновления программ
- Новая вкладка «Обновления»: что можно обновить через winget, Scoop и Chocolatey, с кнопками «Обновить» и «Обновить все». Обновления программ из каталога показываются под их названием и иконкой.
- История обновлений по дням. Успешное обновление можно откатить до предыдущей версии: `winget install --version`, `scoop reset app@версия` или `choco install --version --allow-downgrade`.
- Проверка при запуске и раз в 6 часов; по желанию обновления ставятся в фоне без вопросов. Количество доступных обновлений видно на вкладке.
- Обновления и откаты идут через общую очередь установок с прогрессом и отменой.

### Внешний вид
- Пять тем в «Расширенных → Внешний вид»: Классика, Светлая, OLED, Высокий контраст и Windows 11. На Windows 11 22H2+ тема Windows 11 включает системный фон Mica, на других системах рисует полупрозрачную подложку.
- Свой акцентный цвет (7 готовых или любой через палитру); цвет текста на кнопках подбирается по яркости акцента.
- Масштаб интерфейса: 90 / 100 / 110 / 125 %.
- Четыре вида списков: карточки, список с описанием, компактная таблица и плитки. Переключатель стоит над каждым списком, выбор запоминается.
- Значения внешнего вида проверяются в main-процессе: повреждённые настройки не ломают интерфейс.

## 1.2.5

### Установка
- Ссылки на установщики больше не хранятся в каталоге вручную: `data/installers.json` генерируется из официальных манифестов winget (`npm run catalog:installers`) — актуальная версия, URL, SHA256 и ключи тихой установки.
- Перед запуском установщика сверяется SHA256 из манифеста; при несовпадении или сбое загрузки программа ставится через winget.
- Тип файла определяется по содержимому (EXE / MSI): HTML-страница вместо установщика больше не запускается. Исправлена установка Edge (MSI сохранялся как `.exe`).
- Загрузки только по HTTPS, в том числе после перенаправлений.
- Исправлены 10 неверных winget Id (HWMonitor ставил HWiNFO); генератор сверяет название пакета с каталогом.
- FileZilla и RustDesk, которых нет в winget, ставятся через Chocolatey; Teams, ImageGlass и Rufus — через winget.
- Коды MSI «нужна перезагрузка» (3010 / 1641) и коды успеха из манифестов считаются успешной установкой.

### Рекомендации
- Лента «Для вас» на главной и ранжированная вкладка «Рекомендуем» с причиной на каждой карточке («Вместе с Visual Studio Code»).
- В карточке программы — «Часто ставят вместе» и «Альтернативы» (`data/related.json`).
- Пока ничего не установлено, показывается выбор редакции.

### Безопасность
- Окно приложения работает в песочнице (`sandbox: true`), запрещены новые окна и переходы со страницы приложения.
- `openExternal` открывает только ссылки `http(s)`.
- Внешний каталог проверяется перед использованием.
- Удалён отладочный логгер, который в сборке писал файл и отправлял события на localhost.

### Разработка
- Рабочая конфигурация ESLint (typescript-eslint, react-hooks).
- CI на GitHub Actions и еженедельный PR с обновлением `installers.json`.
- `npm run build` работает в свежем клоне.
- Исходники промо-роликов в `promo/`.
